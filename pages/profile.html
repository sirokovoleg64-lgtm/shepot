Политика конфиденциальности

Последнее обновление: 2025 год

1. Какие данные мы собираем

Приложение «Шёпот» собирает только те данные, которые вы вводите сами:

• Имена — ваше имя и имя партнёра

• Пол — для корректного отображения интерфейса

• Дата начала отношений — для отображения счётчика дней

• Контент — сообщения в чате, желания, фантазии, заметки, фото, аудио

• Настроение — оценки близости, нежности, страсти

• Код пары — для синхронизации между устройствами

2. Как мы храним данные

Все данные хранятся локально на ваших устройствах (localStorage браузера). Мы не используем облачные серверы для хранения ваших личных данных.

3. Синхронизация между устройствами

Приложение создано для двух партнёров. Вы подключаете устройства друг друга через QR-код или код пары. Данные синхронизируются напрямую между устройствами и не передаются на сторонние серверы.

4. Контент 18+

Раздел «За гранью» содержит материалы для взрослых. Доступ к нему подтверждается отдельно с указанием возраста.

5. Удаление данных

Вы можете удалить любые данные через интерфейс приложения. При очистке localStorage или удалении приложения все данные будут безвозвратно удалены.

Пользовательское соглашение

Последнее обновление: 2025 год

1. Общие положения

Используя приложение «Шёпот», вы соглашаетесь с условиями настоящего соглашения.

2. Возрастные ограничения

Приложение содержит контент 18+. Использование лицами младше 18 лет запрещено.

3. Правила использования

• Приложение предназначено для личного использования двумя партнёрами

• Запрещено загружать оскорбительный или противозаконный контент

• Запрещено нарушать права третьих лиц

• Вы несёте ответственность за контент, который создаёте в приложении

4. Ответственность

Приложение предоставляется «как есть». Мы не несём ответственности за возможные сбои, потерю данных или последствия использования приложения.

5. Изменения

Мы можем обновлять условия соглашения. Актуальная версия всегда доступна в разделе «Профиль».
